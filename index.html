01 // Flagship Project

01. GATIS Predictive Analytics

The Motivation: Climate anomalies and volatile trade policies cause severe disruptions in global food supplies. I wanted to build a predictive analytics system capable of forecasting crop yields and highlighting trading patterns to aid agricultural planning.

The Data Challenge: I engineered a memory-efficient Pandas pipeline to clean and process a dataset of 1.1 Million historical records spanning FAOSTAT records across 203 countries and 280 crop categories.

The ML Approach: I trained localized Huber-regularized Ridge Regression models with degree-2 polynomial features. Huber loss was specifically selected to reduce sensitivity to agricultural weather anomaly outliers (droughts/floods), ensuring stable long-term predictions.

Lessons Learned: High-dimensional datasets require statistical rigor. I learned that handling outlier supply years with a robust loss function (Huber) prevents model skewing far better than simply feeding more data into complex neural networks.

Real Estate ML Analytics

An end-to-end data pipeline and machine learning regression model designed to predict property valuations using housing features and multivariate attributes.

Python Scikit-Learn Pandas EDA

Motivation

To understand the core structural factors (size, location indices, rooms) that impact real estate pricing, establishing an end-to-end pipeline from data cleaning to evaluation.

Implementation

  • Designed robust feature engineering scripts to handle missing records and normalize distributions.
  • Executed thorough Exploratory Data Analysis (EDA) to resolve multi-collinearity.
  • Trained and compared regularized regression models (Lasso & Ridge) to ensure generalization.

Lessons Learned

Feature scaling and proper handling of categorical variables are critical. I learned how multi-collinearity can inflate regression coefficients and how regularization stabilizes model weight calculations.

Python Cosine Similarity Pandas Vectorization

Exploring feature representation matrices and metric spaces to compute similarity scores between textual metadata entries.

Implementation

An NLP classification script designed to tokenize emails, extract TF-IDF features, and filter spam using Naive Bayes classifiers.

Python NLP TF-IDF Naive Bayes

Motivation

Gaining hands-on familiarity with text processing pipelines, vector representations of words, and discrete probability-based classification.
